# Offline development bundle

Everything needed to build and run
[pronunciation-app](https://github.com/omipheo/pronunciation-app) on a machine with **no
internet**: the JDK, Android SDK, Gradle and its resolved dependency cache, Python with every
wheel, espeak-ng, and the generated speech models.

Split into 50 MB volumes because GitHub rejects any file over 100 MB.

- **120 volumes**, `pronunciation-offline.part001.rar` .. `part120.rar`
- 1,033 files / 2,296 folders, 7.77 GB uncompressed

## Extract

Download **every** volume into one folder, then open the first one — the rest are found
automatically:

```powershell
7z x pronunciation-offline.part001.rar
```

Or open `part001.rar` in [WinRAR](https://www.win-rar.com/) / [7-Zip](https://www.7-zip.org/).

Check the set is complete before relying on it:

```powershell
7z t pronunciation-offline.part001.rar
```

`Everything is Ok` means every volume arrived intact. Anything else means one is missing or
truncated — re-download before going further.

## Install

```powershell
cd pronunciation-offline
.\offline-install.ps1 -ProjectDir C:\pronunciation-app
```

No administrator rights and no Android Studio. It unpacks the toolchain to `C:\Android`, seeds
the Gradle cache, installs the Python packages from disk, and sets `JAVA_HOME`, `ANDROID_HOME`
and `PATH` at user scope.

Then open a **new** terminal — `PATH` changes only apply to terminals started after them:

```powershell
cd C:\pronunciation-app
.\gradlew.bat assembleDebug --offline
```

`--offline` makes Gradle fail loudly rather than sit waiting on a network that is not there.

## Contents

| Folder | Contents |
|---|---|
| `01-jdk` | Temurin JDK 17 |
| `02-android-sdk` | command-line tools, platform 35, build-tools 34 and 35, platform-tools, emulator, system images for API 26 and 35 |
| `03-gradle` | Gradle 8.9 |
| `04-python` | Python 3.12 embeddable, `get-pip.py`, 44 wheels (CPU-only torch, transformers, onnx, onnxruntime, onnxscript, msvc-runtime, pypinyin) |
| `05-git` | MinGit, portable |
| `06-espeak` | espeak-ng — the phonemiser the Mandarin model was trained with |
| `07-data` | CMUdict and an English word-frequency list |
| `08-gradle-cache` | Gradle's resolved Maven dependencies |
| `09-app-assets` | the generated speech models and lexicons — the app cannot score without these |
| `10-hf-models` | HuggingFace weights, only needed to re-export the models |

Two of those cannot be downloaded and are copies: `08-gradle-cache`, because no published bundle
of a resolved dependency set exists and it can only be obtained by running one build online; and
`09-app-assets`, because those are build outputs generated by the scripts in the main repository.

## Not included, because they are not downloads

**Emulator acceleration** needs one administrator command and a reboot:

```powershell
dism /online /Enable-Feature /FeatureName:HypervisorPlatform /All /NoRestart
```

**Text-to-speech voice data** installs on the device: Settings → System → Languages & input →
Text-to-speech output. English for the English workflow, Chinese for Mandarin.
